Privacy Policy

Three.js Data Visualization

Last updated: September 7, 2026

1. Overview

Three.js Data Visualization is a web-based demonstration application created for an internship assignment. This application allows authorized users to view data from a Google Sheet through an interactive Three.js visualization.

2. Google Account Authentication

The application uses Google OAuth to allow users to securely authorize access to the application. The application does not collect or store users' Google account passwords.

3. Google Sheets Access

The application requests read-only access to a specific Google Sheet using the Google Sheets API. The requested permission is limited to viewing spreadsheet data and does not allow the application to modify, delete, or create spreadsheet data.

4. Information We Access

When a user authorizes the application, the application receives an OAuth access token from Google that is used to retrieve the authorized Google Sheet data. The application only uses the information necessary to display the data visualization.

5. Data Storage

The application does not intentionally store users' Google passwords, Google OAuth credentials, or OAuth access tokens on a server. Access tokens are used by the application to request the authorized Google Sheets data.

6. Data Sharing

The application does not sell, rent, or share users' personal information with third parties for advertising or marketing purposes.

7. Revoking Access

Users can revoke the application's access to their Google account at any time through their Google Account security settings.

8. Changes to This Privacy Policy

This privacy policy may be updated when necessary to reflect changes to the application or its functionality.

9. Contact

If you have questions about this privacy policy or the application, please contact the developer through the contact information provided with the application.
